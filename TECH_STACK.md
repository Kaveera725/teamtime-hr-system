# Technologies, Frameworks & Libraries

This document outlines the core frameworks and libraries utilized across the **Employee Leave & Attendance Management System**.

---

## 🛠️ Frameworks

| Framework | Role in Project | Description |
| :--- | :--- | :--- |
| **ASP.NET Core** | Backend Structure | High-performance, cross-platform web framework used for building the REST API controllers, routing, middleware, and dependency injection. |
| **Entity Framework Core (EF Core)** | Database Layer (ORM) | Object-relational mapper for .NET that manages database queries, migrations, relationships, and data modeling. |
| **React** | User Interface (UI) | Component-based frontend library for building the client-side single-page application (SPA). |
| **Tailwind CSS** | Styling System | Utility-first CSS framework used for responsive, modern, and rapid UI styling. |
| **xUnit** | Test Runner | Automated unit and integration testing framework for verifying business logic and data constraints. |

---

## 📚 Libraries

### Backend (.NET / C#)
* **BCrypt.Net-Next**: Hashes and verifies passwords securely using salted one-way hashing algorithms.
* **Serilog**: Structured logging library that writes diagnostic logs to the console and files.
* **Npgsql (Npgsql.EntityFrameworkCore.PostgreSQL)**: PostgreSQL database provider and driver that connects EF Core to PostgreSQL.

### Frontend (React / TypeScript)
* **Axios**: Promise-based HTTP client for making API requests to the ASP.NET Core backend.
* **date-fns**: Modern JavaScript/TypeScript date utility library for formatting and calculating calendar dates.
* **Recharts**: Composable charting library built on React components for rendering visual analytics and leave statistics.
* **Zod**: TypeScript-first schema declaration and validation library for validating forms and user inputs.
* **lucide-react**: Lightweight icon library providing clean, customizable icons across the UI.
